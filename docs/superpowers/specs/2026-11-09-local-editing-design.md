# 客户纯剪辑版设计

用户已确认：升级 TikTok-Product-Video，复用 tiktok-video-workflow 的 Codex + ChatCut 批量剪辑、配音、字幕、检查和交付；素材只来自客户提供的本地文件。完整工作流仓库保持原样。

## 数据与入口

保留旧版 tk-ops-workspace 工具以兼容历史剪辑，新增 workflow 任务核心、CLI 和可选 MCP。桌面 Codex + ChatCut 为客户默认操作入口，脚本用于任务登记、分析、配音准备、验证和交付。移植来源固定为 c371cf3c87325861df2c6ff735f7b87b8aea5c33；目标基线 dd31351f13017a57b3eeec48984207952aee40c1。

创建任务、导入素材、分析、策划、本地化、ChatCut 编辑与导出、逐条验证、交付按序进行。数量 1–100，市场 MX/BR/ID/PH；原片 SHA256 与任务绑定，成功结果可复用，失败保留证据。桌面操作直接执行客户已批准的任务范围；仅客户明确要求对话精修时逐步确认中文稿。技术回归不能替代真实商品素材质量验收。

## 采集边界

删除网络视频采集脚本、爬虫依赖和默认安装步骤；不移植 collection、unattended 搜索/下载/值班引擎、Evil、Docker 与采集配置。API、CLI、MCP 拒绝 URL 素材及 collection 参数，包括历史保存配置，防止恢复时隐式联网。没有足够本地素材时保存具体缺口、真实进度，等待补料。

配音可以使用已配置 TTS 服务，ChatCut 可保持登录联网；纯剪辑指素材来源限制，不代表全部服务离线。自带本地参考可分析，不在线搜索参考。

## 交付与兼容

保留现有渲染/配音及测试，迁入本地分析、混剪规划、连续动作检查、音色轮换、字幕同步、技术 QA、哈希复用和交付模块。新增 ChatCut 导出登记入口，将客户导出的真实 MP4、SRT、中文说明与真实项目/复核记录绑定本地任务。登记必须验证视频、字幕与素材归属，逐条持久化并更新已交付数，不冒充用户审批。

README、AGENTS、项目 Skills、配置、Windows/macOS 部署和 CI 使用同一纯剪辑合同。Python >=3.12，以 pyproject.toml + uv.lock 为统一安装来源；v0.3.0 为本次本地候选版本。旧文件由 Git 历史及 .git/migration-backups 保存，不覆盖客户素材、运行数据或全局 Codex 配置。先完成本地可审查分支与验证，再按用户明确指令上传 GitHub。

## 验证

验证创建/导入/无素材待办/URL 拒绝/旧采集配置拒绝/API+CLI+MCP 一致性；回归移植的剪辑、声音、字幕、血缘、失败恢复和旧版功能；用本地合成视频运行真实导入、技术检测、交付和复用测试。ChatCut MCP 只读检查单独记录，真实批量商品片、Windows 真机和在线 TTS 未运行时明确列为未验收。
